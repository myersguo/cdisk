# CDisk

[English](README.md)

CDisk 是使用 Rust、Tauri 和 React 构建的本地优先 macOS 磁盘维护工具，提供
“扫描、理解、确认、清理、记录”的完整流程。

[隐私说明](PRIVACY.md) · [安全策略](SECURITY.md) ·
[依赖审计](docs/dependency-audit.md) · [MIT License](LICENSE)

## 安装

当前预构建版本支持 Apple Silicon Mac，使用 ad-hoc 签名且尚未完成 Apple
公证。首次启动时请在 Finder 中右键 CDisk，选择“打开”并确认启动。

使用安装脚本（会校验发布包 SHA-256）：

```bash
curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/myersguo/cdisk/main/scripts/install.sh | sh
```

或使用 Homebrew：

```bash
brew install --cask myersguo/tap/cdisk
```

## 功能

- **七种语言**：支持 English、简体中文、繁體中文、日本語、한국어、
  Español、Français；首次启动跟随 macOS 语言，手动选择后保存在本机。
- **专注的桌面界面**：紧凑侧栏、清晰选中态，候选列表与详情面板可独立滚动。
- **日常清理**：可选择缓存、旧日志、过期临时文件、失败下载残留和逐项废纸篓
  检查，支持路径占用与应用运行保护。
- **项目瘦身**：可配置开发根目录，检查 Git ignore/跟踪内容、嵌套仓库和敏感
  文件；最近 7 天有活动的产物不建议选择。
- **安装包检查**：检查 Downloads 和 Desktop 中的常见安装包，保护已挂载镜像。
- **磁盘分析**：只读分析自定义目录或 Data 卷，支持逐层下钻、返回、按大小排序
  和 Finder 定位。
- **保护名单**：持久化保护路径，更新规则时保留已有扫描结果。
- **操作记录**：逐项保存成功、跳过、失败与中断状态，以及操作前后的磁盘空间。

## 扫描与清理

日常清理、项目瘦身、安装包检查和磁盘分析可以同时扫描。每个页面独立保存进度、
结果、筛选和选择，同一页面同时只运行一个扫描。

暂停会保留当前遍历位置。已经完整扫描且符合条件的候选在暂停期间仍可选择；进入
清理预览时会结束剩余扫描并保留已完成结果。取消也能唤醒暂停任务，并保留已经
完成的候选。未完整扫描的项目必须重新检查后才能清理。磁盘分析结果始终只读。
扫描和取消操作本身不会删除文件。

所有候选初始不勾选。永久删除前，CDisk 会展示确切路径、创建短期确认计划并逐项
重新验证。清理不申请 `sudo`，并保护系统根目录、凭证、应用数据库、Codex 会话
和 VM 运行时。

大量候选的预览校验最多使用四个工作线程，并显示完成数量、当前路径和取消按钮。
预览不会删除数据。真正执行清理时仍保持串行，并在删除每一项前重新完成目录、
Git、挂载、身份、敏感文件和占用检查。扫描后发生变化的项目会被跳过。

## 为什么项目不能勾选？

- **手动保护**：详情中会显示命中的规则。移除规则并重新检查，或在设置页删除规则。
- **镜像已挂载**：先在 Finder 推出磁盘镜像，再重新检查。不能通过删除手动规则
  绕过该保护。
- **路径被占用**：关闭详情中列出的进程，再重新检查。
- **应用运行中**：应用自有缓存和日志会保持保护，直到对应应用完全退出。
- **系统或数据保护**：凭证、Git 跟踪内容等敏感数据不提供强制解锁。
- **状态未知或扫描不完整**：必须重新检查；CDisk 不会跳过失败的安全校验。

修改整份扫描设置前需要结束所有扫描，包括暂停中的扫描。保存设置后，已有结果、
筛选和选择会保留。新增保护规则会立即锁定匹配候选；移除规则后，受影响候选必须
重新检查才能恢复清理资格。

Go、npm、pnpm、Bun、uv、pip 和 Homebrew 等开发缓存使用候选路径级别的打开
文件检查，不会因为任意相关运行时进程存在而整体锁定。Chrome、飞书、微信、
Codex 和 JetBrains 等应用自有缓存或日志还会检查对应 `.app` 是否运行。探针
超时或输出异常会产生“状态未知”，并阻止清理。

日常磁盘卫生使用保守的年龄和文件类型边界：日志和诊断报告至少 30 天未更新；
明确的临时文件及未完成下载至少 7 天未使用。废纸篓按项目展示，并且永远不会被
“选择建议项”自动勾选。

CDisk 当前不提供应用卸载、系统优化、实时监控或 Finder 废纸篓恢复。

## 开发

```bash
pnpm install
pnpm run tauri dev
```

## 验证

```bash
pnpm run verify
```

浏览器回归测试需要先启动 `pnpm dev` 并安装 Playwright：

```bash
pnpm run test:browser
```

`pnpm dev` 启动的浏览器界面会明确标记为演示模式，不执行磁盘操作；原生应用使用
真实 Rust 后端。

## 隐私与安全

- 打包应用不包含遥测、分析、云同步、自动更新或网络上传功能。
- 扫描结果只保存在内存中；设置和最近 100 次清理记录保存在当前用户的
  Application Support 目录。
- 清理历史包含完整本地路径，属于敏感本机数据。详见[隐私说明](PRIVACY.md)。
- 清理只接受后端扫描快照中的候选 ID，并在永久删除前重新验证路径身份、Git、
  挂载、敏感文件和占用状态。
- 安全问题请通过 GitHub Private Vulnerability Reporting 报告。不要在公开
  issue 中附带私有文件或未脱敏的本机路径。详见[安全策略](SECURITY.md)。

## 打包

```bash
pnpm run tauri build --debug --bundles app
```

本地调试包位于 `src-tauri/target/debug/bundle/macos/CDisk.app`。不要在每次验证
之间反复执行 `cargo clean`。可信的公开二进制仍需 Developer ID 签名和 Apple
公证。

公开发布前请按照 [Release checklist](docs/release-checklist.md) 检查源码、依赖、
签名、公证、校验和及隐私材料。不得把本地 `release/` 目录或 debug bundle
作为可信发布产物上传。

本地设置和历史位于：

```text
~/Library/Application Support/com.myersguo.cdisk/
```

无法读取的目录会显示部分结果。需要时可以在 macOS 系统设置中向 CDisk 授予
“完全磁盘访问权限”。未知权限不会被当成 0 字节或可清理结果。
