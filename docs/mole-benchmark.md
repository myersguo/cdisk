## 差距与本轮交付

| Mole 能力 | CDisk 0.2 问题 | CDisk 0.3 |
| --- | --- | --- |
| clean 分类检查 | 多个应用合并成一个候选 | 单路径候选、分类过滤、搜索、排序、风险原因 |
| analyze 目录探索 | 父子目录混合 Top-N，不能下钻 | 指定目录、主目录/Data 卷、直接子项、上一级、双击下钻、Finder 定位 |
| purge 项目产物 | 只凭名称、固定开发根目录 | 自定义开发根、Git ignore/跟踪验证、嵌套 Git/密钥保护、近期活动不默认选择 |
| installer 安装包 | 无独立入口 | Downloads/Desktop 中 DMG/PKG/MPKG/XIP/ISO；不把普通 ZIP 当安装包，拒绝已挂载镜像 |
| dry-run/confirmation | 只显示标题和总量 | 确认页显示逐项路径、大小、原因；重新检查进程、lsof、身份、敏感文件；一次性两分钟令牌 |
| whitelist | 无持久化保护 | 本地保护路径列表；保存后确认计划失效，但保留并更新已有扫描结果 |
| history | 禁用占位页面 | 处理前记录计划，逐项更新，区分清理/跳过/失败/中断；显示磁盘空间前后变化 |
| 持续进度和取消 | 仅全盘有进度 | 全扫描模式共用进度与取消；不完整结果不可清理 |
| uninstall | 无 | 尚未实现；需要 bundle 身份、同 bundle 多副本、共享数据保护 |
| optimize / status | 无 | 尚未实现；不借机执行系统刷新、内存 purge 或停止安全软件 |
| analyze 移到废纸篓 | 无 | 仍只读；原生 Trash、恢复路径与授权尚未实现 |

## 设计取舍

- 优先本地磁盘清理的完整主流程，不一次加入卸载、系统优化、性能监控。
- React：`domain.ts` 为数据契约与纯逻辑，`api.ts` 隔离 Tauri/演示桥接，`App.tsx` 负责交互。
- Rust：`models`、`scanner`、`safety`、`storage` 与薄 command 层分离。
- 不提升权限；无读取权限记为未知/部分结果，不转换为 0 字节成功。
- App Support、Codex 运行时和旧 Claude VM 不再因目录名字被判为可删除。需要从磁盘分析定位并人工判断。
- 四个扫描页可并发：每页独立的 scanId、控制器和后台快照，不相互覆盖。清理/设置操作串行；清理前用最新状态重新校验。设置整表写入需先结束所有扫描。
- 暂停通过条件变量等待，继续保留目录遍历位置，取消能唤醒暂停任务；暂停时可选择已完整扫描候选，预览会结束剩余扫描并保留当前结果；不强行挂起持锁线程。
- 取消只停止后续扫描。完整候选保留清理资格，未完成候选标记 partial；该资格在预览和执行时再次校验。
- 保护来源分为 manual / mounted / busy / app_running / system / unknown / incomplete；只有用户规则可移除，其余需要解决实际原因并重新检查。
- 扫描只读；删除只接受本次后台快照中的候选 ID。用户文本路径仅用于只读分析或保护设置，不能变成删除权限。
- 大型目录检测一次算大小，不在排序比较器里反复扫描。
- 所有候选初始不勾选。“选择建议项”只选择完整、闲置且七天未活动的候选。
- 开发缓存和项目产物按候选路径的实际打开文件判断占用；应用自有缓存/日志额外按精确 `.app` 组件或可执行文件名判断应用状态。占用详情显示进程名和 PID，探针失败则标记 unknown 并拒绝清理。
- 磁盘分析同层项避免父子叠加；跨兄弟目录的硬链接/APFS clone 仍可能共享空间，不能把显示大小当实际回收量。
- 仅安装包常见类型，不解压猜测 ZIP 内容。

## 有限范围

- 项目发现向下 8 层，超过时统计跳过；可添加更近的开发根。
- 最多展示最大的 500 个结果；项目发现最多 10,000 个产物。
- 目录测量最大 128 层，最多跟踪 100,000 个硬链接 inode；超过后标记不完整，拒绝清理。
- 记录保留最近 100 次。崩溃时 running 项代表结果未知，不宣称未删除。
- 不保证实时抵御同一用户恶意进程持续替换目录；身份、父目录 fd、独占隔离、O_NOFOLLOW 和 fsid 检查减少竞态风险。清理前应退出所有相关程序。
- 取消在目录项间检查，不能抢占正在阻塞的内核文件系统调用。

## 验收

- 前端纯逻辑：真实容量状态、选择过滤、搜索排序、单位、路径列表。
- Rust：符号链接/父路径、路径替换、Git 跟踪保护、闲置探针、挂载边界、完整性、取消、目录下钻、设置和操作记录。
- 浏览器：1180×780 和 940×640，独立滚动、筛选、确认、下钻/返回、取消、设置、记录入口。
- 原生：本地打包启动和只读扫描；真实个人缓存不得作为删除测试材料。
